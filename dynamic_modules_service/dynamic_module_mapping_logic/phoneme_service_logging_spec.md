# Phoneme Service Logging & Telemetry Specification

This document defines the standard logging formats and JSON payloads generated by the **Voice Voyage Phoneme Service** when recording phonological process classifications.

---

## 1. Structured Log Format

All process detector logs generated during assessment screening must conform to this structured line format:

```text
[screening-detector] process="{PROCESS_NAME}" sound="{TARGET_SOUND}" position="{POSITION}" age={AGE} grade="{GRADE}" status="{STATUS}" token="{LOG_TOKEN}"
```

### Example Log Lines:
```text
[screening-detector] process="Stopping" sound="s" position="Initial" age=4 grade="Kinder" status="Expected Error" token="STOP_SZ_EXPECTED"
[screening-detector] process="Stopping" sound="s" position="Initial" age=6 grade="Grade 1" status="Delayed" token="STOP_SZ_DELAYED"
[screening-detector] process="Backing" sound="t" position="Initial" age=5 grade="Grade 1" status="Red Flag (Atypical)" token="BACKING_ATYPICAL"
[screening-detector] process="Initial Consonant Deletion" sound="p" position="Initial" age=4 grade="Kinder" status="Red Flag (Atypical)" token="ICD_ATYPICAL"
[screening-detector] process="Gliding" sound="r" position="Initial" age=5 grade="Grade 1" status="Expected Error" token="GLIDE_R_EXPECTED"
[screening-detector] process="Gliding" sound="r" position="Initial" age=8 grade="Grade 3" status="Delayed" token="GLIDE_R_DELAYED"
```
